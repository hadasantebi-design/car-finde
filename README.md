# 🚗 Car Finder — מאתר רכבים אוטומטי

אפליקציה שסורקת אתרי רכב ישראליים (יד2, כלמוביל, שלמה SIXT, אוטו סנטר, אלדן, אוטו קאר אלבר ועוד) פעם ביום, מסננת לפי הקריטריונים שלך, ומרכזת הכל בדשבורד אחד עם סימון "חדש" למודעות שלא ראית.

מה שכבר מוגדר לך:
- **דגמים:** Kia Niro Hybrid, Hyundai Elantra Hybrid, Toyota Corolla Hybrid
- **פילטרים:** שנתון 2021 ומעלה, עד 40,000 ק"מ
- **סריקה:** כל יום ב־08:00 (שעון ישראל)

הכל ניתן לשינוי מתוך האפליקציה (הגדרות) — להוסיף דגמים, לשנות פילטרים, להדליק/לכבות אתרים, ולשנות את שעת הסריקה.

**פיצ'רים:** דשבורד בעברית (עיצוב Redis, RTL, responsive) · סימון "חדש" · **מעקב מחיר** (חץ מגמה + sparkline + גרף היסטוריה מלא) · **מועדפים** עם התראת ירידת מחיר · מסך **מגמות שוק** לפי דגם.

**סטטוס אתרים (נכון ל-2026-07):** אלדן ✅ ואוטו קאר אלבר ✅ עובדים (requests). שלמה SIXT — בהמשך. כלמוביל, אוטו סנטר ויד2 חסומים/JS ודורשים דפדפן (Playwright) — מסלול נפרד.

---

## הרצה מקומית (לבדיקה)

```bash
cd car-finder
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```
פותחים בדפדפן: http://localhost:8000
לחיצה על **"סרוק עכשיו"** מריצה סריקה מיידית.

## פריסה בענן (כדי שירוץ 24/7 בלי שהמחשב דלוק)

בחרת שירות מתארח — כך זה ירוץ כל בוקר לבד. שלוש אפשרויות פשוטות, כולן תומכות ב־Dockerfile שכבר בפרויקט:

### Railway (הכי פשוט)
1. פותחים חשבון ב-https://railway.app
2. New Project → Deploy from GitHub repo (מעלים את התיקייה כ-repo) או "Empty project" + העלאה ידנית.
3. Railway מזהה את ה-Dockerfile ובונה אוטומטית. זהו — האפליקציה חיה בכתובת ציבורית.

### Render
1. https://render.com → New → Web Service
2. Runtime: Docker. Render קורא את ה-Dockerfile לבד.

### Fly.io
```bash
fly launch      # מזהה Dockerfile
fly deploy
```

> **חשוב — שמירת נתונים:** מסד הנתונים נשמר בקובץ `data/listings.db`. בפריסה בענן חברי לו **דיסק קבוע (persistent volume)** ממופה ל-`/app/data`, אחרת ההיסטוריה תתאפס בכל דיפלוי. (ב-Railway/Render/Fly יש הגדרת Volume בלחיצה.)

## איך מוסיפים אתר חדש

הארכיטקטורה מודולרית — כל אתר הוא "תוסף":

1. פותחים את `scrapers/dealerships.py` ומוצאים את המחלקה של האתר (למשל `KalmobilScraper`).
2. ממלאים את `SEARCH_URL` — נכנסים לאתר, מסננים לדגם מסוים, ומעתיקים את ה-URL מסרגל הכתובות. משאירים `{make}`/`{model}` במקומות המתאימים אם רלוונטי.
3. רוב האתרים המודרניים מטמיעים נתונים בפורמט schema.org (JSON-LD) — במקרה כזה זה יעבוד אוטומטית בלי מאמץ נוסף.
4. אם אין JSON-LD, ממלאים את `SELECTORS` (card / title / price / km / year / link) לפי ה-HTML של הדף.

להוספת אתר חדש לגמרי: יוצרים מחלקה שיורשת מ-`DealershipScraper`, נותנים לה `name` ו-`label`, ומוסיפים אותה ל-`scrapers/__init__.py` → `REGISTRY`. מפעילים אותה מהאפליקציה (הגדרות → אתרים).

## הערות כנות וחשובות

- **יד2 והאתרים חוסמים בוטים.** הסקרייפרים הם best-effort. אם אתר מפסיק להחזיר תוצאות — כנראה שינו את המבנה, וצריך עדכון קטן בקוד (בעיקר בפונקציות ה-parse). שמרתי על מבנה שקל לתחזק.
- **מזהי יד2 (manufacturer/model IDs)** ב-`scrapers/yad2.py` צריכים אימות מול חיפוש חי — נכנסים ליד2, מסננים לדגם, וקוראים את הפרמטרים מה-URL. עדכני אם שונה.
- **תנאי שימוש:** לחלק מהאתרים יש תנאים שמגבילים סריקה אוטומטית. שמרי על תדירות נמוכה (פעם ביום מספיק) ואל תעמיסי.
- **אתרים שדורשים דפדפן אמיתי:** אם אתר בנוי כולו ב-JavaScript, `requests` יחזיר דף ריק. במקרה כזה צריך להוסיף רינדור עם Playwright (`pip install playwright && playwright install chromium`) — מסמנים `NEEDS_BROWSER = True` באותו סקרייפר, ואני יכול להרחיב את הקוד לכך כשנגיע לזה.

## מבנה הפרויקט

```
car-finder/
├── app.py            # שרת ה-FastAPI + תזמון יומי + ה-API
├── engine.py         # מריץ את כל הסקרייפרים ושומר תוצאות
├── storage.py        # מסד נתונים (SQLite) + זיהוי כפילויות + סימון "חדש"
├── config.yaml       # כל ההגדרות: דגמים, פילטרים, אתרים, תזמון
├── scrapers/
│   ├── base.py           # מחלקת בסיס משותפת
│   ├── yad2.py           # סקרייפר יד2
│   ├── dealerships.py    # כלמוביל, שלמה SIXT, אוטו סנטר, אלדן, אלבר
│   └── __init__.py       # רישום האתרים
├── static/index.html # הדשבורד (עברית, RTL, פילטרים בסגנון יד2)
├── Dockerfile
└── requirements.txt
```
